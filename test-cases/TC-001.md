# TC-001: Проверка граничного значения: попытка добавить 0 единиц товара

**ID:** TC-001  
**Тип:** Функциональное тестирование / Тест-дизайн (Граничные значения)  
**Статус:** Open  

**Предусловия:**  
Пользователь авторизован, открыта страница любого товара в магазине.  

**Шаги воспроизведения:**  
1. В поле ввода "Количество" ввести значение `0`.  
2. Нажать кнопку "В корзину" (или кликнуть мышкой вне поля ввода, чтобы снять фокус).  

**Ожидаемый результат:**  
Товар не добавляется в корзину. Система выводит сообщение об ошибке: "Минимальное количество для заказа: 1 шт." (либо поле ввода автоматически возвращается к значению `1`).
