# 📋 Тест-кейсы (Test Cases)

В этой папке собраны примеры тест-кейсов, написанных для учебных платформ (например, OWASP Juice Shop).

## 🎯 Цель
Продемонстрировать навыки написания структурированной тестовой документации и применение техник тест-дизайна на практике:
- Классы эквивалентности (Equivalence Partitioning)
- Граничные значения (Boundary Value Analysis)
