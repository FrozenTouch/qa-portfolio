# TC-003: Проверка граничного значения: попытка добавить 11 единиц товара (превышение лимита)

**ID:** TC-003  
**Тип:** Функциональное тестирование / Тест-дизайн (Граничные значения)  
**Статус:** Open  

**Предусловия:**  
Пользователь авторизован, открыта страница товара, на складе достаточно товара.  

**Шаги воспроизведения:**  
1. В поле ввода "Количество" ввести значение `11`.  
2. Нажать кнопку "В корзину".  

**Ожидаемый результат:**  
Товар не добавляется в корзину (или добавляется только 10 шт.). Система выводит сообщение об ошибке: "Максимальное количество одного товара в заказе: 10 шт.".
