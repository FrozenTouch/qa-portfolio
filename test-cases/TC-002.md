# TC-002: Проверка граничного значения: успешное добавление 1 единицы товара

**ID:** TC-002  
**Тип:** Функциональное тестирование / Тест-дизайн (Граничные значения)  
**Статус:** Open  

**Предусловия:**  
Пользователь авторизован, открыта страница товара, товар есть в наличии.  

**Шаги воспроизведения:**  
1. В поле ввода "Количество" ввести значение `1`.  
2. Нажать кнопку "В корзину".  

**Ожидаемый результат:**  
Товар успешно добавляется в корзину. Счетчик корзины увеличивается на 1. Ошибок валидации нет.
