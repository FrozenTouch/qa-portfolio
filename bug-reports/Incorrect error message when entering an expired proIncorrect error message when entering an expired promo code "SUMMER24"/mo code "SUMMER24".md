### Предусловия

Открыт доступ к странице магазина:
https://www.realbugz.com/ru/store/

___

### Шаги воспроизведения

1. Открыть страницу магазина: https://www.realbugz.com/ru/store/
2. Войти или  зарегистрироваться в аккаунте
3. Добавить любой товар и зайти в корзину (https://www.realbugz.com/ru/store/cart)
4. Ввести промокод "SUMMER24"
5. И нажать кнопку `Применить`


### Ожидаемый результат
После нажатия кнопки `Применить` пользователь увидит надпись что "срок действия промокода истёк" и им нельзя воспользоваться 

### Фактический результат
После нажатия кнопки `Применить` пользователь видит что "Промокод не найден"

___

### Влияние (Impact)
- У пользователя может возникнуть недоумение почему промокод не найден  
- Подрывает доверие к магазину и маркетинговым акциям
- Нарушает требования ТЗ (должно быть сообщение «Срок действия промокода истёк»)
