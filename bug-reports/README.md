# Bug Reports

Баг-репорты, найденные при тестировании учебных сайтов (AcademyBugs).

## Список отчётов

| Файл | Описание |
|------|----------|
| `academybugs-freeze-quantity.md` | Страница зависает при выборе количества товара 5 или 50 |
| `academybugs-twitter-share-404.md` | Кнопка Twitter Share ведёт на несуществующий домен (риск фишинга) |

## Формат отчётов

Каждый отчёт содержит:
- Окружение (браузер, ОС, сайт)
- Шаги воспроизведения
- Ожидаемый результат
- Фактический результат
- Влияние (если применимо)
