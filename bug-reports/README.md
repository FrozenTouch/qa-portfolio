# Bug Reports

Баг-репорты, найденные при тестировании учебных платформ.

## 🐞 AcademyBugs
| Файл | Описание |
|------|----------|
| `academybugs-freeze-quantity.md` | Страница зависает при выборе количества товара 5 или 50 |
| `academybugs-twitter-share-404.md` | Кнопка Twitter Share ведёт на несуществующий домен (риск фишинга) |

## 🐞 Realbugz
| Файл | Описание |
|------|----------|
| `realbugz-broken-internal-link-404.md` | Битая внутренняя ссылка ведёт на страницу 404 |
| `realbugz-heading-not-centered.md` | Заголовок статьи выровнен не по центру |
| `realbugz-non-working-share-buttons.md` | Кнопки «Поделиться» не реагируют на нажатие |

## 📋 Формат отчётов
Каждый отчёт содержит:
- Окружение (браузер, ОС, сайт)
- Предусловия
- Шаги воспроизведения
- Ожидаемый результат
- Фактический результат
- Влияние (Impact)
- Доказательства (скриншоты)
- Рекомендации по исправлению
