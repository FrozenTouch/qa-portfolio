# QA Portfolio — FrozenTouch

Портфолио начинающего QA-тестировщика.  
Здесь собраны баг-репорты и учебные проекты, демонстрирующие навыки ручного тестирования.

## 📂 Что внутри

| Папка | Что там |
|-------|---------|
| `bug-reports/` | Баг-репорты с учебных платформ (AcademyBugs и Realbugz) |
| `test-cases/`| Примеры тест-кейсов с применением техник тест-дизайна |

## 🐞 Найденные баги:

- **AcademyBugs**: функциональные и UI-баги (зависание при выборе количества, неработающая кнопка Twitter Share).
- **Realbugz**: баги с анализом кода через DevTools (битые ссылки 404, неработающие кнопки «Поделиться», визуальные дефекты вёрстки).
